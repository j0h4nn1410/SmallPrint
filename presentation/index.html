How it works

Open any page → click the badge

  1. 1Detection — JSON-LD, Amazon adapter, wording detector, or LLM fallback reads the page already open — no bot detection
  2. 2T&C fetch — backend follows page links, checks domain cache, common paths, then Tavily (company domain only)
  3. 3LLM extraction — Claude Haiku fills the schema; every field needs a verbatim quote or returns null
  4. 4Company lookup — Wikidata SPARQL → GLEIF LEI → Companies House, joined on company number to load records from SQLite
  5. 5Cards stream in — SSE, card by card as each lookup resolves — no waiting for the slowest one

SMALL/PRINTCore principle
Core principle

Evidence, not verdicts

Every claim has a verbatim quote, a source URL, and a date. The code re-fetches the source and checks the quote is in it.

If the LLM can't find a verifiable quote in the source, the field returns null — not a guess. Quote or null. No invented values.

Estimates are labelled: low / mid / high ranges with source URLs — never presented as exact. A missing returns policy IS a finding.

No ethics scores. Regulator decisions preferred over press. The user decides what matters.

// Four honest card states

found — value + quote + link
estimated — value + range + source
not_found — said plainly
           (a missing policy
            IS a finding)
n_a — doesn't apply
